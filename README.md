# Bangladesh Bike Racing 🇧🇩
A browser-based arcade bike traffic game. Built with HTML, CSS, and Canvas JavaScript. No framework or paid API required.

## Run locally
Open `index.html` in a modern browser. For a local server, run `python -m http.server 8000` inside this folder and visit `http://localhost:8000`.

## Controls
- Left/Right arrows or A/D: steer
- Up/W: accelerate
- Down/S: brake
- R: restart after crash
- Mobile: on-screen controls

## Deploy free on Vercel
1. Upload this folder to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. Framework Preset: **Other**; Build Command: leave blank; Output Directory: `.`
5. Click **Deploy**.

This is a 2D arcade prototype, not a full 3D simulator. Traffic, score bonuses, collision/game over, speedometer, and Bangladesh-inspired road details are implemented locally.
