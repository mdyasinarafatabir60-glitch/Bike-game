# Bangladesh Bike Racing 3D — Mobile Edition

A browser-based 3D arcade bike traffic game with Bangladesh-inspired roads, Bangla road signs, traffic vehicles, score/speed HUD, selectable bike colors, fullscreen mode and touch controls.

## Run locally
Open `index.html` in a modern browser, or use VS Code Live Server. Three.js is loaded from jsDelivr, so internet access is required.

## Deploy on Vercel
1. Upload all files in this folder to the root of a GitHub repository.
2. Import the repository at https://vercel.com/new
3. Framework Preset: `Other`; Build Command empty; Output Directory `.`.
4. Click Deploy.

## Controls
Desktop: Arrow keys or A/D to steer, Up/W to accelerate, Down/S to brake. Press R to restart after a crash. Mobile: use the on-screen controls. Tap FULL SCREEN for immersive play.

Note: This is an arcade-style 3D prototype, not a photorealistic simulator. The sound button is a UI placeholder.
